# Mastermind — اللعبة الذهنية

لعبة أرقام عربية كاملة، مبنية بـ HTML وCSS وJavaScript دون مكتبات أو اتصال بالإنترنت.

## التشغيل

1. فك ضغط الملف أولًا.
2. افتح `index.html` في متصفح حديث مثل Edge أو Chrome أو Firefox أو Safari.
3. لا يلزم تثبيت أو خادم أو npm. اترك الملفات والمجلدات بجانب بعضها.

## قواعد اللعب

- تركيز: 3 خانات. كلاسيكي: 4 خانات. محترف: 5 خانات.
- ثماني محاولات لكل جولة. الأرقام من 0 إلى 9، دون تكرار. الصفر مسموح في البداية.
- تظهر ثلاثة أعداد لكل تخمين: صحيح بمكانه، صحيح بمكان آخر، وغير موجود.
- التلميحات إجمالية ولا تكشف حالة كل خانة منفردة.
- التخمين الناقص أو المكرر لا يستهلك محاولة.
- الفوز في المحاولة الثامنة يُحسب فوزًا.
- بدء جولة جديدة قبل إنهاء الحالية لا يُحسب خسارة.

## التحكم

- اسحب رقمًا من البنك إلى خانة. يعمل السحب بمؤشر الفأرة واللمس باستخدام Pointer Events.
- أو انقر الخانة ثم الرقم؛ الإدخال يبدأ من اليسار إلى اليمين.
- نقل رقم مستخدم إلى خانة مشغولة يبدّل الرقمين.
- اسحب رقمًا من الخانة إلى بنك الأرقام لمسحه.
- لوحة المفاتيح: الأرقام الإنجليزية والعربية، الأسهم لاختيار الخانة، Backspace أو Delete لمسحها.
- Enter للتحقّق عندما يكون التركيز على خانة أو مساحة اللعب؛ Enter على زر رقم يختار ذلك الرقم كالمعتاد.
- زر «مسح» يمسح التخمين الحالي فقط.
- تغيير المستوى أو إعادة الجولة يطلب التأكيد إذا كانت الجولة الحالية تحتوي تقدمًا.

## الحفظ والصوت والتصميم

- يتم حفظ الجولة والإعدادات والإحصائيات محليًا على المتصفح متى سمح بالتخزين.
- في وضع التصفح الخاص أو عند حظر التخزين، تستمر اللعبة دون ضمان الحفظ.
- سلوك التخزين تحت file:// يختلف بين المتصفحات. نقل المجلد أو تبديل المتصفح قد يفصل سجلّ الحفظ.
- الوقت لحساب التفكير فقط، ولا يوجد حد زمني. يتوقف عند إخفاء الصفحة، ولا يُضاف وقت إغلاق المتصفح.
- الإحصائيات إجمالية، وأفضل محاولة محسوبة للمستوى المختار.
- مؤثرات صوتية اختيارية، مع وضع فاتح وداكن ودعم تقليل الحركة.
- لا تُحمّل خطوط أو صور أو ملفات صوت من الإنترنت.

## فحص الحل — حسب طلب رامي

تم الاحتفاظ بالتعليمة التالية في `script.js` داخل `logSecret()`:

```js
console.log(myRandomArr);
```

افتح أدوات المطور ثم Console لرؤية الرمز عند بدء الجولة أو استرجاعها. وهو محفوظ كنصوص للحفاظ على الصفر الأول. لإخفاء الحل لاحقًا، احذف هذا السطر. هذه لعبة محلية؛ رمزها موجود أيضًا في الذاكرة والتخزين، ولا يُقصد بها منع فحص المصدر.

## الملفات

- `index.html`: الواجهة.
- `style.css`: التصميم والتجاوب والمؤثرات.
- `engine.js`: قواعد اللعبة وتقييم التخمينات، منفصلة عن الواجهة لسهولة الفهم والاختبار.
- `script.js`: التحكم والسحب والصوت والحفظ والتفاعل.
- `assets/favicon.svg`: الأيقونة المحلية.

للرفع على GitHub Pages: ضع محتويات هذا المجلد في جذر المستودع دون تغيير المسارات.
